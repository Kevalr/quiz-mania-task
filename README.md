# Quiz Application with Timer and Score
## Objective
A simple quiz application where users can:
- Select a category (e.g., JavaScript Basics, React Basics)
- Answer multiple-choice questions
- Get 10 seconds to answer each question
- See their final score at the end
---
## Features
- Category selection page
- One question at a time
- Four answer options per question
- 10-second timer for each question
- "Next" button to move to the next question manually
- Automatic move to next question if time runs out
- Score calculated at the end
- Final result shows:
  - Number of correct answers
  - Number of unanswered questions
  - A message like "Great job!" or "Keep practicing!"
- Highlights correct (green) and incorrect (red) answers
---
